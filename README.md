# ドパパス！ サポートサイト

静的HTMLのサポート・プライバシーポリシー・利用規約ページ。ビルド不要。外部スクリプト・アクセス解析は使用しません。

ローカル確認：このフォルダで `python3 -m http.server 8000` を実行して http://localhost:8000/ を開いてください。

公開URL：https://hanachiru.github.io/dopapass-site/

publicリポジトリのmainブランチ、ルートをGitHub Pagesで公開しています。コミット・pushすると公開内容が更新されます。

サイト更新時はこのリポジトリでコミット・pushし、親側でもsiteの参照をコミット・pushしてください。
